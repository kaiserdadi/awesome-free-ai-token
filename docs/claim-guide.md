# 领取攻略：按顺序做，一小时拿完主要额度

> 截止日和规则以官方页面为准。本页只负责告诉你**入口在哪、坑在哪**。

## 第一步：零门槛的，先花 10 分钟

不用实名、不用绑卡的先领，失败了也不亏。

| 平台 | 入口路径 | 注意 |
|---|---|---|
| 智谱 GLM | open.bigmodel.cn → 注册 → 控制台 → API Keys | 2000 万永久额度。顺手把 GLM-4.7-Flash 加进常用模型，它本身 0 元 |
| Google AI Studio | aistudio.google.com → Google 账号登录 → Get API key | 不要信用卡。**免费层内容可能被用于改进产品，别喂敏感数据** |
| Groq | console.groq.com → 邮箱注册 → API Keys | 30 RPM / 1000 请求/天。按组织限流，多开 Key 无效 |
| Cloudflare Workers AI | dash.cloudflare.com → Workers AI | 计量单位是 Neurons 不是 Token，先跑一次看扣多少 |
| OpenRouter | openrouter.ai → 注册 → Keys | 模型名带 `:free` 后缀的才免费。50 请求/天 |
| Mistral | console.mistral.ai → 注册 | 选 Experiment 档。数值官方已不公布，控制台看 |
| GitHub Copilot Free | GitHub → Settings → Copilot | 每月 2000 补全 + 50 次 Chat。学生认证可白嫖 Pro |
| WorkBuddy | 装桌面客户端 → 左下角头像 → Buddy 加油站 | 只有客户端有，网页版和手机端都没有 |

## 第二步：要实名的，一次性领完

国内平台基本都卡实名，一次做完，之后注册其他家会快很多。

### 阿里云百炼（量最大）
1. 登录阿里云 → 实名认证；
2. 进[百炼控制台](https://bailian.console.aliyun.com)，首页找「新手资源」横幅；
3. **手动点领取**（不会自动到账），每个模型 100 万 Token；
4. 累计约 7000 万，**90 天有效**，仅北京地域。

> 坑：70 多个模型逐个领很烦，但值得。只领你近期要用的，领多了全是过期浪费。

### 腾讯云 TokenHub
1. 腾讯云控制台 → 搜 TokenHub → 「新用户福利免费体验」；
2. 每个模型领 100 万，**领取日起 1 年有效**；
3. 活动截止 12-31，但额度是按领取日算一年，早领早用。

### 火山引擎方舟（每日续杯）
1. 火山引擎 → 实名 → 方舟控制台；
2. 开通模型 → 创建 API Key；
3. 每个模型 50 万「安心体验」额度，一次性；
4. 再进「11.11 AI 智选」活动页，实名后每模型每天 200 万自动刷新。

> 坑：「安心体验」超额会自动暂停，不会产生账单——但别去开自动转付费。

### 国家超算互联网（限时，11-30）
1. [scnet.cn](https://www.scnet.cn) → 注册 → 实名；
2. 下载最新版客户端，登录即享旗舰模型词元不限量；
3. 新用户再领 1 亿词元科学计算智能体额度；
4. 活动页可 0.1 元秒杀 5000 万词元包。

### 商汤日日新（长期公测）
1. [platform.sensenova.cn/token-plan](https://platform.sensenova.cn/token-plan) → 实名 → 开通 Token Plan；
2. 无需绑卡、无需提交 Demo；
3. 额度按滚动窗口给：5 小时 12 万积分、每周 120 万；
4. 老用户 10-27 已自动升到新上限，不用重新申请。

### 阶跃星辰 Step Plan（最高 75 天）
1. 登录 platform.stepfun.com → 进 Step Plan 活动页；
2. 领登录赠送的 15 天；
3. 随便跑一次模型调用 → 再得 15 天（不拉人也有 30 天）；
4. 想拉满再邀好友，每人 15 天、上限 3 人。

> **最大的坑**：调用地址必须填 `https://api.stepfun.com/step_plan/v1`。填成标准的 `/v1` 也能调通，但**不算「首次调用」**，还会从你自己的余额里扣钱。

### 七牛云（300 万 / 2 年）
1. [qiniu.com/ai/models](https://www.qiniu.com/ai/models) → 注册 → 实名；
2. 创建第一个 API Key，300 万 Token 自动激活；
3. 一个 Key 通吃 50+ 模型，OpenAI / Anthropic 双协议；
4. 有效期 2 年，是少见的慢过期额度。

## 第三步：设成每日固定动作

这些不是「领一次」，是「每天点一下」。建议直接做进早晨的开机流程。

| 动作 | 在哪点 | 能拿 | 漏了会怎样 |
|---|---|---|---|
| WorkBuddy 签到 | 桌面客户端 → 左下角头像 → Buddy 加油站 | 100 积分 | 当天作废，连签清零 |
| Qoder 领 Credits | 桌面端 → 用量面板 → 礼物图标 | 100 Credits | 错过窗口不补 |
| 豆包签到 | 电脑版 → 左侧活动位 / 我 → 免费额度 | 约 200 | 漏一天少 200 |
| 七牛每日额度 | 认证后自动发放 | 1 亿/天 | 0 点重置 |
| 商汤滚动窗口 | 自动，无需操作 | 5h 12 万积分 | 窗口滚动，不用就浪费 |

> **别写脚本刷签到。** 平台风控就是冲这个来的，抓到会回收积分、限制账号。为一天一百分把号搭进去不划算。

## 第四步：海外大额的（按需）

### NVIDIA NIM
1. [build.nvidia.com](https://build.nvidia.com) → 邮箱注册；
2. 验证弹窗里 Location 可以选 China，+86 手机号能通；
3. 进 API Keys 页生成密钥（**默认 12 个月有效期，手动改成永不过期**）；
4. Key 只显示一次，先复制存好。

> 坑：列表里有两个 GLM，**GLM-5.3 已于 10-28 下线**，能用的免费版是 GLM-5.3-Flash。新模型上架那几天速度最好，之后会越来越慢。

### Cerebras / Groq（要速度的）
两家都不需要信用卡。Cerebras 每天 100 万 Token 但上下文只有 8K；Groq 请求上限最高但每日 Token 有天花板。适合 Agent 里的高频小调用，不适合长文档。

## 领完之后：先跑通，再规划

**领到额度的当天就跑一次真实调用。** 理由：

- 确认 Key 能用、Base URL 没错、协议兼容；
- 看清实际扣多少（尤其按倍率/积分计费的那些）；
- 额度有效期从「领取日」开始算，不用就是纯浪费。

跑通之后再决定买不买付费套餐——先摸清每月真实消耗，比直接冲最高档省钱得多。
